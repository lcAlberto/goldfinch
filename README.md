# Goldfinch investimentos Landing Page

Site criado em Nuxt3

## Setup

Instalar as dependencias

```bash
# npm
npm install
```

## Development Server

Para rodar em desenvolvimento local, no endereço `http://localhost:3000`:

```bash
# npm
npm run dev
```

## Production

Buildar a aplicação:

```bash
# npm
npm run build
```

Build local:

```bash
# npm
npm run preview
```

Trabalho realizado sob encomenda em Fevereiro de 2024. O visual do site pode ter sido alterado pelo cliente a partir dessa data.

Check out the [deployment documentation](https://nuxt.com/docs/getting-started/deployment) for more information.
